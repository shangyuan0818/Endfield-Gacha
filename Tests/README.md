# 图表统计回归测试

需要 Python 3、支持 C++20 的 GCC 或 Clang：

```sh
python3 Tests/run.py
```

默认开启 UBSan，遇到未定义行为即失败。可用 `CXX=clang++` 或 `--cxx clang++` 切换编译器；不支持 UBSan 的环境可加 `--no-sanitize`。测试进程或编译失败都会返回非零退出码。临时编译文件自动清理。

脚本从当前 `gui.cpp` 原样抽取枚举、桶、统计结果、CDF 初始化、KS 和 `Calculate`，排除 Win32 / GDI+ 部分后直接编译。没有另一份统计实现，也不需要 Windows SDK。若源码结构改变导致抽取边界缺失或不唯一，脚本会明确报错。

覆盖的回归：

- 武器 UP 落在第 1 / 10 / 71 抽时，图表频数按申领末尾聚合；平均抽数与 hazard 保持原始单抽口径。
- 图表使用的 KS 最大点确实落在导出的 ECDF 上，且差值与文字 D 一致。
- 辉光样本 `[13,31,62,69,71,75,110,140,179,241]` 的 D 约为 `0.0692239567`，最大点保留在 241；不能读取尚未填充的 `cdf[241]=0`，也不能截掉理论有效范围外的最大点。
- 259 号频数边界、过大的 `max_pity`、空样本及重复使用的最大点输出。
- 非武器频数保持单抽粒度，重构混合样本标志仍按原有规则传给图表。

本套测试验证真实统计核心及其图表输入，不编译或执行 GDI+ 绘图。合并前仍应按仓库既有方式在 Windows 上完成原生构建，并手动检查：

1. 武器 UP 的 ECDF 在十连边界跳变，显示申领聚合说明，图中 D 与文字统计相同；MRL 和平均抽数仍按单抽统计。
2. 辉光样本最大偏差位于 240 抽以后时，仍显示后端 D 和尾部截断说明，不画超出理论范围的连线。
3. 重构样本含多个 UP 时显示混合说明，不显示 UP KS 标记；综合六星 KS 不受影响。
4. 缩放窗口以及最大点位于绘图区左右边缘时，KS 标签留在绘图区内。

这些原生绘图检查不能由本测试的通过结果替代。
